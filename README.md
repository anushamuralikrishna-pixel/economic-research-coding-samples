## 1. Empirical Research Replication (Python)

This project was completed for ECON 148: Applied Data Science for Economists at UC Berkeley in Spring 2026.

The objective was to computationally reproduce the empirical findings of a paper by Michael Thaler examining how individuals assess the credibility of news in relation to their political preferences. The project involved cleaning and transforming the original research data, reproducing econometric analyses and figures, and evaluating the consistency of the reproduced results with the original findings.

The project demonstrates experience in data management, regression analysis, empirical replication, data visualization, and reproducible research.

Repository structure:

notebooks/: Main Jupyter notebook containing the empirical analysis.

src/: Python scripts supporting the analysis.

data/: Cleaned datasets used in the reproduction.

figures/: Figures generated through the analysis.
  
[View Python coding sample](./thaler-reproduction/notebooks/thaler_reproduction_notebook.ipynb)

## 2. Treatment Effects Analysis (R)

This project was completed for ECON 174: Global Poverty and Impact Evaluation at UC Berkeley.

The analysis examines the short- and long-term effects of three treatment programs on household outcomes. It estimates treatment-specific effects, constructs an indicator for receiving any treatment, and investigates treatment effect heterogeneity by baseline literacy.

The project demonstrates experience in:

Data manipulation using dplyr

Treatment effect estimation using linear regression

Short- and long-term impact evaluation

Heterogeneous treatment effects using interaction terms

Regression table generation using stargazer
[View R coding sample](./treatment_effects_analysis/treatment_effects_analysis.R)
